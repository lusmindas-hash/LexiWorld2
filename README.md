# LexiWorld: The Glitch Attack

LexiWorld is a browser-based English-learning adventure with three connected A1–A2 game missions.

## Included missions

1. **Syntax Surfer** — a three-lane grammar action runner.
2. **The Lost Timeline** — a clue-search and grammar detective game.
3. **Sound Safari** — a listening challenge with character, location, and sequence rounds.

## Intro video

The 15-second opening video is stored at `assets/video/lexiworld-intro.mp4`. It starts with sound after the player presses **Play intro**.

## Run locally

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.
