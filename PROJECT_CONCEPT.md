# LexiWorld: The Glitch Attack — Project Concept

LexiWorld is a connected three-game adventure for A1–A2 English learners. The Glitch has damaged the Sentence Engine, the Time Archive, and the Echo Map. The player restores each system by completing a different game genre.

## Visual direction

The homepage uses a large game-console cover on the right side of the main title. Mission cards follow one shared grid, so all labels, titles, descriptions, feature tags, and buttons align at the same height.

## Language

All visible interface text, instructions, feedback messages, and game tasks are in English.
